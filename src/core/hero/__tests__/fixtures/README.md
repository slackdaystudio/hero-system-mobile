# Parsed character fixtures

Parsed-XML JSON fixtures for the `hero/` + `traits/` golden master, one per
`.hdc` in `fixtures/characters/`, plus `manifest.json` (per-fixture template +
trait counts).

## Provenance

Generated by running the sanitized corpus through the **legacy `File.js` parse
config** — `react-native-xml2js` with `explicitArray:false`, `mergeAttrs:true`,
`emptyTag:null`, `explicitRoot:false`, `change-case` camelCasing of tag/attr
names, and the legacy `_parseXmlValue` value coercion — then deleting the
portrait (`image`/`portrait`), which the cost/roll math never touches.

Each fixture is therefore the exact object shape that `HeroDesignerCharacter.getCharacter()`
consumes. The golden master runs `getCharacter(fixture)` (and decorates every
trait) on both the legacy engine and the ported `core`, asserting identical output.

These are **provisional**: the bootstrap generator is a one-off script. When the
`infra/files` parser lands in Phase 2, it becomes the real, in-repo generator and
these are regenerated from it.

## Coverage (see manifest.json)

37 characters — Heroic (5E/6E), Superheroic (5E/6E, the bulk), AI6E, and 4 custom
(object) templates. Gaps: no Normal/Automaton/Computer genre templates.
